# Network Architecture and Cloud Security

This document summarizes network architecture concepts, network security principles, cloud computing, and software-defined networking.

---

## Network Architecture

Network architecture refers to the design and structure of a network, including how devices, systems, and services communicate.

### Common Components
- Routers
- Switches
- Firewalls
- Servers
- Endpoints

---

## Network Security

Network security involves protecting the confidentiality, integrity, and availability of data and systems across a network.

### Common Security Measures
- Firewalls
- Intrusion Detection / Prevention Systems (IDS/IPS)
- Network Segmentation
- VPNs
- Access Controls

---

## On-Premises Networks

Traditional network infrastructure hosted and maintained within an organization’s physical environment.

### Advantages
- Greater direct control
- Local data storage
- Custom infrastructure design

### Challenges
- Higher maintenance costs
- Hardware management
- Physical infrastructure requirements

---

## Cloud Computing

Delivery of computing services over the internet instead of through local infrastructure.

### Benefits
- Scalability
- Flexibility
- Reduced hardware costs
- Remote accessibility

---

## Software-Defined Networking (SDN)

A network architecture approach that uses software-based controllers to manage network traffic and infrastructure.

### Benefits
- Centralized network management
- Improved flexibility
- Faster configuration changes
- Better scalability

---

## Why This Matters

Understanding network architecture and cloud environments helps security professionals:
- Protect infrastructure effectively
- Understand attack surfaces
- Secure hybrid/cloud environments
- Analyze network-based threats
