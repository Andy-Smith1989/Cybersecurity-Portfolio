# Network Protocols and Network Security

This document summarizes network protocols, network security tools, and system identification concepts.

---

## Network Protocols

Network protocols define how data is transmitted and communicated between devices.

### Common Network Protocols
- HTTP/HTTPS – Web communication
- DNS – Domain name resolution
- DHCP – Assigns IP addresses
- FTP – File transfers
- SMTP – Email sending

---

## Wireless Protocols

Wireless communication standards enable secure network connections.

### Examples
- Wi-Fi (802.11)
- WPA2 / WPA3 – Wireless encryption protocols

### Security Considerations
- Weak encryption increases risk
- Secure configurations are critical

---

## Firewalls

Firewalls monitor and control incoming and outgoing network traffic.

### Purpose
- Block unauthorized access
- Allow legitimate traffic
- Enforce security rules

---

## Virtual Private Networks (VPNs)

VPNs create secure, encrypted connections over public networks.

### Benefits
- Protect data in transit
- Improve privacy
- Secure remote access

### Common Protocols
- IPSec
- WireGuard

---

## Proxy Servers

Proxy servers act as intermediaries between users and the internet.

### Purpose
- Hide user identity
- Filter traffic
- Improve security and control

---

## Security Zones

Security zones segment networks into different trust levels.

### Examples
- Internal network
- External network
- DMZ (demilitarized zone)

### Purpose
- Limit access between zones
- Reduce attack surface

---

## Subnetting and CIDR

Subnetting divides networks into smaller segments.

### Benefits
- Improves organization
- Enhances security
- Reduces broadcast traffic

### CIDR
- Classless Inter-Domain Routing
- Allows flexible IP address allocation

---

## Why This Matters

Understanding protocols and network security helps:
- Analyze network traffic
- Identify suspicious behavior
- Protect systems and data
- Support incident response investigations
