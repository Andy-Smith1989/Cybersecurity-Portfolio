# Home Network Risk Assessment

## Objective
Identify potential security risks in a typical home network environment.

## Assets Identified
- Wi-Fi router
- Personal computer
- Mobile devices
- Tablets
- Smart Watches
- Smart TV

## Potential Risks
- Weak Wi-Fi password
- Outdated router firmware
- Unauthorized device access

## Risk Evaluation
- Weak password > High risk
- Outdated firmware > Medium risk
- Unknown devices > High risk

## Recommendations
- Use a strong Wi-Fi password, change regularly, use password manager
- Regularly update router firmware
- Monitor connected devices and traffic
