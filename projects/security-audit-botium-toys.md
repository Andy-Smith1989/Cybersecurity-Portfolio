# Security Audit – Botium Toys

## Objective
Conduct a security audit of a fictional company, Botium Toys, to assess current security controls, identify compliance gaps, and provide recommendations to improve the organization’s security posture.

## Scope
The audit reviewed Botium Toys’:
- Employee devices and equipment
- Internal network and internet access
- Data storage and retention practices
- Legacy systems
- Security controls and compliance posture

## Risk Assessment Summary
- Overall Risk Score: **8/10 (High)**
- Key risks identified:
  - Inadequate asset management
  - Lack of encryption for customer credit card data
  - No intrusion detection system (IDS)
  - No disaster recovery plan or backups
  - Weak password policy / no password management system
  - Excessive employee access to sensitive data

## Controls Evaluated
Reviewed administrative, technical, and physical controls including:
- Least privilege
- Disaster recovery planning
- Password policies
- Firewall protections
- IDS/IPS
- Backups
- Antivirus
- Encryption
- Physical security controls

## Compliance Frameworks Considered
- PCI DSS
- GDPR
- SOC 1 / SOC 2

## Recommendations
- Implement encryption for cardholder and sensitive customer data
- Deploy intrusion detection system (IDS)
- Enforce least privilege and separation of duties
- Establish disaster recovery and backup processes
- Implement centralized password management
- Improve password complexity requirements
