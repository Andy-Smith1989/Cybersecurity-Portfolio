# Security Frameworks and Controls

This document summarizes common security frameworks and the types of security controls used to protect systems and data.

---

## Security Frameworks

Security frameworks provide structured guidance for managing cybersecurity risks and implementing security programs.

### Common Frameworks

#### NIST Cybersecurity Framework (CSF)
- U.S. framework for managing cybersecurity risk
- Core Functions:
  - Identify
  - Protect
  - Detect
  - Respond
  - Recover

#### NIST Risk Management Framework (RMF)
- Structured process for selecting and managing security controls
- Focuses on risk assessment and continuous monitoring

#### CIS Critical Security Controls
- Prioritized best practices for cyber defense
- Designed to improve organizational security posture

#### ISO/IEC 27001
- International standard for information security management systems

---

## Security Controls

Security controls are safeguards used to reduce security risk.

### Administrative Controls
Policies and procedures that guide security practices.

Examples:
- Security awareness training
- Acceptable use policies
- Background checks

---

### Technical Controls
Technology-based protections that enforce security.

Examples:
- Firewalls
- Antivirus software
- Multi-factor authentication
- Encryption

---

### Physical Controls
Measures used to protect physical assets and facilities.

Examples:
- Security guards
- Badge access systems
- Locked server rooms
- Surveillance cameras

---

## Why Frameworks and Controls Matter

Organizations use frameworks and controls to:
- Reduce cybersecurity risk
- Standardize security practices
- Meet compliance requirements
- Protect systems, users, and data
