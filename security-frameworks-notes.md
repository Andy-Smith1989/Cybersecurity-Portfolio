# Security Frameworks & Compliance Standards

This document provides an overview of common cybersecurity frameworks and regulations.

---

## FERC / NERC

- **FERC (Federal Energy Regulatory Commission)** oversees energy systems in the U.S.
- **NERC (North American Electric Reliability Corporation)** develops reliability standards.

### Key Focus:
- Protecting the power grid
- Critical infrastructure security
- CIP (Critical Infrastructure Protection) standards

---

## FedRAMP

- Federal Risk and Authorization Management Program
- Standardized approach to cloud security for U.S. government systems

### Key Focus:
- Cloud service provider security
- Continuous monitoring
- Authorization to operate (ATO)

---

## CIS (Center for Internet Security)

- Provides best practices for securing systems

### Key Focus:
- CIS Critical Security Controls (18 controls)
- System hardening benchmarks

---

## GDPR (General Data Protection Regulation)

- European Union data privacy regulation

### Key Focus:
- Protecting personal data
- User consent and rights
- Data breach notification requirements

---

## PCI DSS

- Payment Card Industry Data Security Standard

### Key Focus:
- Protecting credit card data
- Secure payment processing
- Network security controls

---

## HIPAA

- Health Insurance Portability and Accountability Act (U.S.)

### Key Focus:
- Protecting patient health information (PHI)
- Privacy and security of medical data

---

## ISO (ISO/IEC 27001)

- International standard for information security management systems (ISMS)

### Key Focus:
- Risk management
- Security policies and procedures
- Continuous improvement

---

## SOC Reports

### SOC 1
- Focuses on financial reporting controls

### SOC 2
- Focuses on security and data protection

#### SOC 2 Trust Principles:
- Security
- Availability
- Processing Integrity
- Confidentiality
- Privacy

---

## Why These Matter

Understanding these frameworks helps organizations:
- Meet legal and regulatory requirements
- Protect sensitive data
- Reduce security risks
- Build trust with customers
