# Security Tools Overview

This document summarizes foundational security tools commonly used in cybersecurity operations.

---

## SIEM (Security Information and Event Management)

A SIEM tool collects and analyzes logs from multiple systems in one central location.

### Purpose
- Monitor security events
- Detect suspicious activity
- Support incident investigation
- Improve visibility across systems

### Common SIEM Tools
- Splunk
- IBM QRadar
- Microsoft Sentinel

---

## Packet Sniffers

Packet sniffers capture and analyze network traffic.

### Purpose
- Inspect packets moving across a network
- Troubleshoot network issues
- Detect suspicious or malicious traffic
- Analyze protocols and communications

### Common Packet Sniffers
- Wireshark
- tcpdump

---

## Intrusion Detection Systems (IDS)

IDS tools monitor network or system activity for malicious behavior.

### Purpose
- Detect unauthorized access attempts
- Alert security teams of suspicious activity
- Monitor network traffic for threats

### Types of IDS
- Network-Based IDS (NIDS)
- Host-Based IDS (HIDS)

---

## Why These Tools Matter

Security analysts use these tools to:
- Monitor environments for threats
- Investigate incidents
- Analyze suspicious activity
- Improve organizational security posture
