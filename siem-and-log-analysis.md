# SIEM and Log Analysis

This document summarizes Security Information and Event Management (SIEM) tools and the role of log analysis in cybersecurity.

---

## What Is a SIEM?

A SIEM (Security Information and Event Management) platform collects, centralizes, and analyzes logs from multiple systems to help security teams monitor for threats and investigate suspicious activity.

### Primary Functions
- Aggregate logs from multiple sources
- Detect suspicious or malicious activity
- Generate alerts for analysts
- Support incident investigation and response

---

## Common SIEM Tools

### Splunk
A popular SIEM and data analytics platform used to search, monitor, and analyze machine-generated data.

#### Common Uses
- Log searching and filtering
- Alert creation
- Incident investigation
- Dashboard visualization

---

### Google Chronicle
A cloud-native security analytics platform designed for large-scale log ingestion, detection, and investigation.

#### Common Uses
- Threat detection
- Log retention and analysis
- Security investigations
- Large-scale event correlation

---

## Types of Security Logs

### Network Logs
Record network traffic and communications.

Examples:
- Firewall logs
- Router logs
- IDS/IPS logs

---

### System Logs
Record operating system and device activity.

Examples:
- Login attempts
- Process execution
- System errors

---

### Application Logs
Record events from software and applications.

Examples:
- Web server logs
- Database logs
- Authentication events

---

## Why SIEM and Logs Matter

Security analysts use SIEM tools and log analysis to:
- Detect threats in real time
- Investigate suspicious behavior
- Identify attack patterns
- Improve organizational visibility
