# TCP/IP and OSI Models

This document summarizes the TCP/IP model, OSI model, and how network communication occurs between systems.

---

## Network Communication Basics

Network communication is the process of transmitting data between devices across a network.

### Communication Process
- Data is broken into packets
- Packets travel across the network
- Receiving device reassembles the data
- Protocols govern how communication occurs

---

## TCP/IP Model

The TCP/IP model is the foundational framework for modern internet/network communication.

### 1. Network Access Layer
- Handles physical transmission of data
- Includes hardware and local network protocols

### 2. Internet Layer
- Routes packets between networks
- Uses IP addressing

### 3. Transport Layer
- Ensures reliable or connectionless delivery
- Uses TCP and UDP

### 4. Application Layer
- Provides network services to applications
- Includes protocols like HTTP, DNS, SMTP

---

## OSI Model

The OSI model is a conceptual framework used to understand how networks communicate.

### 1. Physical Layer
- Physical transmission of raw bits

### 2. Data Link Layer
- Local network communication / MAC addressing

### 3. Network Layer
- Routing / IP addressing

### 4. Transport Layer
- End-to-end communication / TCP / UDP

### 5. Session Layer
- Establishes and manages sessions

### 6. Presentation Layer
- Data formatting / encryption / compression

### 7. Application Layer
- User-facing network services

---

## Why These Models Matter

Understanding these models helps security professionals:
- Troubleshoot network issues
- Analyze packet captures
- Understand protocol behavior
- Identify where attacks occur in the network stack
